PAIRING‑ROLE verbindet:
ATOM · HYPNOSE · MANA · DIAMANT · FLOW · ESEE · synth · ID
mit den 4u‑Reaktionsrollen.

4u‑ROLE‑SYSTEM

OK     → Zustimmung / Grün
NOK    → Ablehnung / Rot
FLOW   → Weiter / Bewegung
BREAK  → Abbruch / Stop
ECHO   → Spiegelung / Rückwurf
VOID   → Neutral / Leere
ROOT   → Rückkehr / Reset

PAIRING‑ROLE ordnet diese 7 Reaktions‑Typen.
