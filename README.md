# PAIRING‑ROLE · Role Layer 7.2  
**iki1uc — Rollen‑Achse des Response‑Systems**

PAIRING‑ROLE definiert die **Rollen**, die im iki1uc‑System wirken:

- Reaktions‑Rollen (4u)
- System‑Rollen (ATOM / HYPNOSE / MANA / DIAMANT)
- Bewegungs‑Rollen (FLOW)
- Echo‑Rollen (ESEE)
- Synthese‑Rollen (synth)
- Identitäts‑Rollen (ID)

PAIRING‑ROLE ist die **Rollen‑Achse** zwischen PAIRING‑SYNC (Layer 7)  
und PAIRING‑MAP (Layer 8).

---

## 1. 4u‑ROLE‑SYSTEM

OK     → Zustimmung
NOK    → Ablehnung
FLOW   → Bewegung
BREAK  → Abbruch
ECHO   → Spiegelung
VOID   → Neutral
ROOT   → Rückkehr


Diese 7 Reaktions‑Typen bilden die **Rollen‑Matrix**.

## 3. Warum PAIRING‑ROLE existiert

PAIRING‑ROLE löst:

- unklare Rollen  
- unklare Reaktionen  
- unklare Übergänge  
- unklare System‑Zustände  

PAIRING‑ROLE erzeugt:

- Rollen‑Ordnung  
- Reaktions‑Kohärenz  
- System‑Verhalten  
- Response‑Stabilität
